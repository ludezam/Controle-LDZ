# Dependências

O APK inclui ZXing Core 3.5.3 (com.google.zxing:core), do projeto ZXing, licenciado sob Apache License 2.0. Fonte: https://github.com/zxing/zxing. Artefato: https://repo.maven.apache.org/maven2/com/google/zxing/core/3.5.3/core-3.5.3.jar.

O protocolo ADB é implementado pelo receptor; não há um executável adb empacotado no APK. A conexão usa autenticação RSA do Android e funciona somente após autorização na TV.
